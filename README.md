# Day 1 – Agentic AI Foundations

## Overview

This project demonstrates the difference between a plain LLM chatbot,
a rule-based workflow, and a tool-using AI agent.

The systems are tested using a college course-fee problem.

## Technologies Used

- Python
- OpenAI-compatible API
- Groq
- Large Language Model
- JSON Schema Tool Calling
- Python Virtual Environment
